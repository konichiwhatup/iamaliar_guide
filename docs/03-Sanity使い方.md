# I AM A LIAR — Sanity 使い方ガイド vol.2

## コンテンツの更新方法

このドキュメントは、サイトのコンテンツ(商品・記事・ヒーロー画像)を自分で更新するための手順書です。

コードや技術的な知識は一切不要です。管理画面にログインして、入力して、ボタンを押すだけで更新できます。

**管理画面URL:** https://www.sanity.io/manage/project/22x23c52

---

## Sanity とは

Sanity は、サイトに表示するコンテンツを管理するための「専用の管理画面」です。

たとえば商品の写真や説明文、記事のテキストなどは、コードの中に直接書かれているわけではなく、Sanity というサービスの中に保管されています。

Sanity の管理画面で変更すると、数秒〜1分ほどで実際のサイトに反映されます。
コードを触る必要はありません。管理画面から操作するだけです。

---

## ドキュメントの状態と色

各コンテンツ(商品・記事など)には「状態」があり、管理画面上でバッジの色によって区別されています。

- 🟢 **緑 — 公開中(Published)** サイトに表示されている状態。訪問者に見えている。
- 🟫 **茶色 — 下書き(Draft)** 編集中・未公開の状態。サイトには出ていない。
- 🟪 **紫 — 予約投稿(Scheduled)** 指定した日時に自動公開されるよう予約された状態。

### 基本の操作

| 操作 | 意味 | できる状態 | サイトへの影響 |
|------|------|-----------|--------------|
| Publish(公開) | 下書きをサイトに公開する | 茶色(Draft)のとき | 約1分後に反映 |
| Unpublish(非公開) | 公開中をサイトから引っ込める | 緑(Published)のとき | 約1分後に消える |
| Delete(削除) | データごと消す | どの状態でも可 | 即時・戻せない |

> **注意:** Unpublish(非公開)は、緑(公開中)の状態のときだけ選択できます。下書き(茶色)の画面には Unpublish は表示されません。非公開にしたい場合は、まず公開中のドキュメントを開いてください。

## 公開済みのコンテンツを編集する

すでにサイトに公開されている商品・記事を変更したい場合、直接書き換えるのではなく「ドラフト(下書き)」を経由して編集します。

1. **編集したいドキュメントを開く**
   左メニューから商品や記事をクリックして開きます。

2. **画面上部に「Published」と表示されている状態を確認する**
   緑色のバッジが出ていれば公開中です。

3. **内容を編集し始める**
   テキストや画像を変更すると、Sanity が自動的に「Draft(下書き)」を作成します。この時点ではまだサイトには反映されません。

4. **「Publish」を押して上書き公開する**
   Draft の内容が公開中の内容を上書きし、サイトに反映されます。

> 編集中に「やっぱりやめたい」場合は「Discard changes」(変更を破棄)を押すと、Draft が消えて公開中の状態に戻ります。公開されたデータは変わりません。

> **注意:** 「Draft(下書き)」の画面から「Unpublish」は選択できません。非公開にしたい場合は、まず「Publish」をクリックして公開中の状態に戻してから、改めて「Unpublish」を選択してください。

## 商品(Collection)を追加・編集する

### 新しい商品を追加する

1. 左メニューの「Product」をクリック
2. 画面右上の鉛筆アイコン(新規作成ボタン)を押す — クリックすると空の入力フォームが開きます
3. 各項目を入力する(詳細は下記)
4. 右上の「Publish」を押して公開

### 入力項目の説明

| 項目名 | 内容 | 必須 |
|--------|------|------|
| Title | 商品名 | ✓ |
| Slug | URLに使われる英字の識別子。自動生成されるので基本触らなくてOK | |
| Status | available(販売中)/ sold-out(完売)/ coming-soon(近日公開)など | |
| Category | 商品のカテゴリ | |
| Price | 価格(数字のみ) | |
| Sizes | 取り扱いサイズ(複数選択可) | |
| Description | 商品の短い説明文 | |
| Story | 制作背景・コンセプトなど読み物的なテキスト | |
| Material | 素材の説明 | |
| Featured Image | 一覧ページや詳細ページのメイン画像(1枚) | |
| Gallery | 詳細ページのギャラリー画像(複数枚) | |
| Published At | 公開日。並び順に影響します | |

### 既存の商品を編集する

- 左メニューの「Product」→ 編集したい商品をクリック
- 変更 → 「Publish」で上書き反映

### 商品を非公開にする / 削除する

- **非公開:** 商品を開いて「Unpublish」— サイトから消えるが、データは残る
- **削除:** 「Delete」— データごと消える。戻せないので注意

## 記事(Journal)を追加・編集する

### 新しい記事を追加する

1. 左メニューの「Journal」をクリック
2. 画面右上の鉛筆アイコン(新規作成ボタン)を押す — クリックすると空の入力フォームが開きます
3. 各項目を入力する
4. 「Publish」を押して公開

### 入力項目の説明

| 項目名 | 内容 |
|--------|------|
| Title | 記事タイトル |
| Slug | URLの識別子。自動生成でOK |
| Excerpt | 一覧ページに表示される短い説明文 |
| Category | 記事のカテゴリ |
| Tags | タグ(複数つけられる) |
| Cover Image | 記事のカバー画像 |
| Body | 記事本文。リッチテキストエディタで入力 |
| Related Products | 紐づける商品。記事ページから商品への導線になる |
| Author | 著者名 |
| Published At | 公開日(並び順に影響) |

## ホームの見た目を変える(Home Hero)

トップページのヒーロー画像・キャッチコピーは「Home Hero」という設定から変更します。商品や記事と違い、これは1つだけ存在する特別な設定です。

1. 左メニューの「Home Hero」をクリック
2. 変更したい項目を編集する
3. 「Publish」を押して反映

| 項目名 | 内容 |
|--------|------|
| Hero Image | トップページに大きく表示されるメイン画像 |
| Hero Caption | 画像上に重なるキャッチコピーのテキスト |
| Hero Image Opacity | 画像の透明度(0=完全透明 〜 1=不透明)。0.6〜0.8 あたりがバランスよい |
| Hero Link | 画像クリック時に飛ぶ商品ページ |

## 写真のアップロードについて

写真は「拡張子(ファイルの種類)」と「サイズ」に気をつけるだけで、ほぼ問題なくアップロードできます。

### 拡張子(ファイルの種類)について

ファイル名の末尾についている「.jpg」「.png」「.heic」のような文字が拡張子です。種類によって、サイト上での表示や取り扱いが変わります。

| 拡張子 | 説明 | 使えるか |
|--------|------|----------|
| .jpg / .jpeg | 写真に最もよく使われる形式。ファイルサイズが小さく、サイトの表示が速い。商品・ヒーロー画像はこれが最適。 | ◎ 推奨 |
| .webp | jpgよりさらにファイルサイズが小さい最新形式。表示速度の面で最も優秀。使えるなら積極的に。 | ◎ 推奨 |
| .png | 背景が透明な画像(ロゴなど)に向く。写真には不向き(ファイルが重くなる)。 | ○ OK |
| .heic / .heif | iPhone がデフォルトで保存する形式。Sanity にはアップロードできるが、古いブラウザや環境では表示されないことがある。変換してから使うことを推奨。 | △ 要注意 |
| .gif | 動くアニメーション画像。ファイルが非常に重くなりがちで、サイトの読み込みが遅くなる原因になる。 | △ 非推奨 |
| .tiff / .raw / .bmp | カメラの高解像度データなど。ファイルが極端に重く、Webサイトでの使用には向かない。 | ✕ 不可 |

> iPhone で撮った写真を Safari からそのままアップロードする場合、iOS が自動で JPEG に変換してくれます。変換作業は不要です。

> **Mac を経由する場合**(AirDrop・USB でファイルをコピーしてから Sanity にアップロードするとき)は、.heic のまま取り込まれることがあります。その場合: 写真アプリで対象画像を右クリック →「書き出す」→「JPEGで書き出す」で変換してからアップロードしてください。

### ファイルサイズとピクセル数

- **推奨サイズ:** 横幅 1500〜2500px 程度
- それ以上(4000px〜)の超高解像度は、Sanity が自動でリサイズしてくれるが、アップロードに時間がかかる
- **推奨ファイルサイズ:** 1枚あたり 5MB 以内を目安に。それ以上でもアップロードはできるが、サイトの読み込みに影響が出ることがある

### ファイル名のつけ方

- 英数字とハイフン・アンダースコアのみを使う
- 日本語のファイル名(例: 商品写真.jpg)は文字化けの原因になることがあるので避ける

| 良い例 | 悪い例 |
|--------|--------|
| `product-01.jpg` | `商品01.jpg` |
| `hero-summer-2026.jpg` | `ヒーロー画像.jpg` |
| `journal-cover-01.webp` | `IMG 3847.HEIC` |

## 「あれ?」と思ったとき

### Publishしたのにサイトに反映されない

- Sanity の CDN(配信システム)のキャッシュが残っていることがあります
- 1〜2分待ってから、ブラウザを `Cmd+Shift+R`(Mac)または `Ctrl+Shift+R`(Windows) で強めにリロードしてみてください

### 画像がサイトに表示されない

- Sanity Studio で該当ドキュメントの画像欄が空になっていないか確認
- .heic のまま使っていないか確認。なっていたら JPEG に変換して再アップロード
- ファイル名に日本語が入っていないか確認

### アップロードが途中で止まる / エラーになる

- ファイルサイズが大きすぎる可能性があります。10MB 以上のファイルは一度圧縮してから試してください
- ブラウザをリロードして再度試す

### Publish ボタンが押せない / グレーアウトしている

- 必須項目(Title・Slug など)が未入力の場合に起きます
- 赤いエラー表示の項目を確認して、すべて入力してから再度試してください
