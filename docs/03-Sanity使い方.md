## Sanity とは

Sanity は、サイトに表示するコンテンツを管理するための「専用の管理画面」です。

商品の写真や説明文、記事のテキスト、ニュースなどは、コードの中に直接書かれているわけではなく、Sanity というサービスの中に保管されています。Sanity の管理画面で変更すると、**数秒〜1分ほどで実際のサイトに反映**されます。

---

## ドキュメントの状態と色

各コンテンツには「状態」があり、管理画面上でバッジの色によって区別されています。

- 🟢 **緑 — 公開中(Published):** サイトに表示されている状態。訪問者に見えている。
- 🟫 **茶色 — 下書き(Draft):** 編集中・未公開の状態。サイトには出ていない。
- 🟪 **紫 — 予約投稿(Scheduled):** 指定した日時に自動公開されるよう予約された状態。

### Draft と Published の関係

**Draft(下書き)と Published(公開中)は、同じドキュメントの「編集中バージョン」と「公開バージョン」**です。別々のものではなく、1つの商品・記事に対してセットで存在します。

- **Published に書いてある内容** = 今まさにサイトに表示されているもの
- **Draft に書いてある内容** = 編集中のもの。まだサイトには反映されていない

Published の画面では内容を直接書き換えることができません。編集を始めると Sanity が自動的に Draft を作り、そちらに変更が入ります。Draft で編集 → Publish することで、はじめてサイトに反映されます。

### 「どれを編集しているか」の確認方法

左のメニューで商品や記事の一覧を見ると、Draft があるものは名前の横に **「Draft」** と表示されます。同じ名前(タイトル)の Published と Draft が対応しています。

たとえば「商品A」を開いて編集中であれば、左メニューに「**商品A — Draft**」と表示されます。これが「商品A」の公開バージョンに紐づいた下書きです。別の商品のDraftとは混ざりません。

### 基本の操作

| 操作 | 意味 | できる状態 | サイトへの影響 |
|------|------|-----------|--------------|
| Publish(公開) | 下書きをサイトに公開する | 茶色(Draft)のとき | 約1分後に反映 |
| Unpublish(非公開) | 公開中をサイトから引っ込める | 緑(Published)のとき | 約1分後に消える |
| Delete(削除) | データごと消す | どの状態でも可 | 即時・戻せない |

> **注意:** Unpublish は、緑(公開中)の状態のときだけ選択できます。Draft の画面には Unpublish は表示されません。非公開にしたい場合は、まず公開中のドキュメントを開いてください。

## 公開済みのコンテンツを編集する

すでにサイトに公開されている商品・記事・ニュースを変更したい場合、直接書き換えるのではなく「Draft(下書き)」を経由して編集します。

1. **編集したいドキュメントを開く** — 左メニューから商品や記事をクリックして開きます。
2. **「Published」と表示されている状態を確認する** — 緑色のバッジが出ていれば公開中です。この画面の内容が今サイトに表示されているものです。
3. **内容を編集し始める** — テキストや画像を変更すると、Sanity が自動的に「Draft(下書き)」を作成します。**編集した内容は Draft に入り、この時点ではまだサイトには反映されません。**
4. **「Publish」を押して上書き公開する** — Draft の内容が Published の内容を上書きし、サイトに反映されます。

> 編集中に「やっぱりやめたい」場合は「Discard changes」(変更を破棄)を押すと、Draft が消えて Published の状態に戻ります。サイトに公開されているデータは変わりません。

> **注意:** Draft の画面から「Unpublish」は選択できません。非公開にしたい場合は、まず「Publish」をクリックして公開中の状態に戻してから、改めて「Unpublish」を選択してください。

## 商品(Product)を追加・編集する

### 新しい商品を追加する

1. 左メニューの「**Product**」をクリック
2. 画面右上の **鉛筆アイコン(新規作成ボタン)** を押す — 空の入力フォームが開きます
3. 各項目を入力する(下記参照)
4. 右上の「**Publish**」を押して公開

### 入力項目の説明

| 項目名 | 内容 | 必須 |
|--------|------|:----:|
| Title | 商品名 | ✓ |
| Slug | URLに使われる英字の識別子。「Generate」を押せば自動生成されるので基本触らなくてOK | ✓ |
| Status | `available`(販売中) / `sold-out`(完売) / `coming-soon`(近日公開) | |
| Category | 商品のカテゴリ | |
| Price | 価格(数字のみ。円記号不要) | |
| Sizes | 取り扱いサイズ(複数選択可) | |
| Description | 商品の短い説明文。一覧ページや詳細ページに表示される | |
| Story | 制作背景・コンセプトなど、読み物的なテキスト | |
| Material | 素材の説明 | |
| Featured Image | 一覧ページや詳細ページのメイン画像(1枚) | |
| Gallery | 詳細ページのギャラリー画像(複数枚。ドラッグで並び順変更可) | |
| Published At | 公開日。一覧ページの並び順に影響します | |

### 既存の商品を編集する

左メニューの「Product」→ 編集したい商品をクリック → 変更 → 「Publish」で上書き反映。

### 商品を非公開にする / 削除する

- **非公開:** 商品を開いて「Unpublish」— サイトから消えるが、データは残る
- **削除:** 「Delete」— データごと消える。戻せないので注意

## 記事(Journal)を追加・編集する

### 新しい記事を追加する

1. 左メニューの「**Journal**」をクリック
2. 右上の **鉛筆アイコン** を押す
3. 各項目を入力する(下記参照)
4. 「**Publish**」を押して公開

### 入力項目の説明

| 項目名 | 内容 | 必須 |
|--------|------|:----:|
| Title | 記事タイトル | ✓ |
| Slug | URLの識別子。「Generate」で自動生成 | ✓ |
| Excerpt | 一覧ページに表示される短い説明文 | |
| Category | 記事のカテゴリ | |
| Tags | タグ(複数つけられる) | |
| Cover Image | 記事のカバー画像 | |
| Body | 記事本文。リッチテキストエディタで入力。見出し・太字・画像挿入が可能 | |
| Related Products | 紐づける商品。記事ページから商品への導線になる | |
| Author | 著者名 | |
| Published At | 公開日(一覧の並び順に影響) | |

## ニュース(News)を追加・編集する

ニュースは **カテゴリによって入力できる項目が変わります**。カテゴリを選んでから残りの項目を入力してください。

### カテゴリの種類

| カテゴリ | 用途 | カテゴリ専用の項目 |
|----------|------|-------------------|
| **イベント・展示** | 展示会・ポップアップなど | 開催場所 / Google Maps URL / 開催期間 |
| **お知らせ** | 一般的なインフォメーション | なし |
| **着用紹介** | Instagram投稿や掲載ページの紹介 | 投稿・掲載リンク(URL) |

### 新しいニュースを追加する

1. 左メニューの「**ニュース (News)**」をクリック
2. 右上の **鉛筆アイコン** を押す
3. **カテゴリーをまず選ぶ** — 選択後に専用項目が表示されます
4. 各項目を入力する(下記参照)
5. 「**Publish**」を押して公開

### 入力項目の説明

**全カテゴリ共通**

| 項目名 | 内容 | 必須 |
|--------|------|:----:|
| タイトル | ニュースのタイトル | ✓ |
| Slug | URLの識別子。「Generate」で自動生成 | ✓ |
| カテゴリー | イベント・展示 / お知らせ / 着用紹介 | ✓ |
| 概要 | 一覧ページに表示される短い説明文 | |
| カバー画像 | 一覧・詳細ページのメイン画像 | |
| 本文 | リッチテキストエディタで入力。見出し・太字・画像挿入が可能 | |
| 公開日 | 一覧の並び順と表示日付に使われる。自動で今日の日時が入る | |

**「イベント・展示」のみ表示される項目**

| 項目名 | 内容 | 入力例 |
|--------|------|--------|
| 開催場所 | 会場の名前・住所など | `代官山 蔦屋書店 2号館` |
| Google Maps URL | 会場の Google Maps リンク | `https://maps.google.com/...` |
| 開催期間 | 開催の日付範囲 | `2026.06.15 — 06.30` |

**「着用紹介」のみ表示される項目**

| 項目名 | 内容 | 入力例 |
|--------|------|--------|
| 投稿・掲載リンク (URL) | Instagram 投稿や掲載ページの URL | `https://www.instagram.com/p/...` |

## ホームの見た目を変える(Home Hero)

トップページのヒーロー画像・キャッチコピーは「Home Hero」という設定から変更します。商品や記事と違い、これは1つだけ存在する特別な設定です。

1. 左メニューの「**Home Hero**」をクリック
2. 変更したい項目を編集する
3. 「**Publish**」を押して反映

| 項目名 | 内容 |
|--------|------|
| Hero Image | トップページに大きく表示されるメイン画像 |
| Hero Caption | 画像上に重なるキャッチコピーのテキスト |
| Hero Image Opacity | 画像の透明度(0=完全透明 〜 1=不透明)。0.6〜0.8 あたりがバランスよい |
| Hero Link | 画像クリック時に飛ぶ商品ページ |

## 写真のアップロードについて

### 拡張子(ファイルの種類)について

| 拡張子 | 説明 | 使えるか |
|--------|------|:--------:|
| .jpg / .jpeg | 写真に最もよく使われる形式。ファイルサイズが小さく表示が速い | ◎ 推奨 |
| .webp | jpg よりさらに軽い最新形式。使えるなら積極的に | ◎ 推奨 |
| .png | 背景が透明な画像(ロゴなど)向き。写真には不向き(ファイルが重い) | ○ OK |
| .heic / .heif | iPhone のデフォルト形式。古いブラウザで表示されないことがある | △ 要注意 |
| .gif | ファイルが非常に重くなりがち | △ 非推奨 |
| .tiff / .raw / .bmp | Web 向きでない | ✕ 不可 |

> iPhone で撮った写真を Safari からそのままアップロードする場合、iOS が自動で JPEG に変換してくれます。変換作業は不要です。

> **Mac 経由の場合** (AirDrop・USB でファイルをコピーしてからアップロード): .heic のまま取り込まれることがあります。写真アプリで対象画像を右クリック →「書き出す」→「JPEG で書き出す」で変換してからアップロードしてください。

### ファイルサイズとピクセル数

- **推奨ピクセル数:** 横幅 1500〜2500px 程度
- **推奨ファイルサイズ:** 1枚あたり 5MB 以内を目安に

### ファイル名のつけ方

日本語のファイル名は文字化けの原因になることがあるので、**英数字・ハイフン・アンダースコアのみ**を使う。

| 良い例 | 避けたい例 |
|--------|-----------|
| `product-01.jpg` | `商品01.jpg` |
| `news-event-2026.jpg` | `ニュース画像.jpg` |
| `journal-cover-01.webp` | `IMG 3847.HEIC` |

## 「あれ?」と思ったとき

### Publish したのにサイトに反映されない

Sanity の CDN(配信システム)のキャッシュが残っていることがあります。1〜2分待ってから、ブラウザを `Cmd+Shift+R`(Mac)または `Ctrl+Shift+R`(Windows) で強めにリロードしてみてください。

### 画像がサイトに表示されない

- Sanity Studio で該当ドキュメントの画像欄が空になっていないか確認
- .heic のまま使っていないか確認。なっていたら JPEG に変換して再アップロード
- ファイル名に日本語が入っていないか確認

### アップロードが途中で止まる / エラーになる

ファイルサイズが大きすぎる可能性があります。10MB 以上のファイルは一度圧縮してから試してください。ブラウザをリロードして再度試す。

### Publish ボタンが押せない / グレーアウトしている

必須項目(Title・Slug・カテゴリーなど)が未入力の場合に起きます。赤いエラー表示の項目を確認して、すべて入力してから再度試してください。

### ニュースのカテゴリ専用項目が表示されない

カテゴリーを選択してから少し待つか、画面を一度スクロールしてみてください。カテゴリー選択後に専用の入力欄が表示されます。
