## Sanity とは

Sanity は、サイトに表示するコンテンツを管理するための「専用の管理画面」です。

作品の写真や説明文、ニュースなどは、コードの中ではなく Sanity の中に保管されています。Sanity で変更して Publish すると、**数十秒〜1分ほどで実際のサイトに反映**されます。

### Sanity で変えられるもの・変えられないもの

| Sanity で変えられる | Sanity では変えられない(コードの修正が必要) |
|---|---|
| Gallery の作品(追加・写真・説明文・ステータスなど) | Brand Story(ホームの5つの章の文章) |
| News の投稿 | Philosophy ページの文章 |
| ホームの背景画像とキャプション | Contact ページの文章 |
| | 価格欄の見せ方(「¥ + 白いバー」「PRICELESS.」表記) |
| | LINE・Instagram のリンク先 |

## ドキュメントの状態

各コンテンツには「状態」があります。

- **公開中(Published):** サイトに表示されている状態
- **下書き(Draft):** 編集中・未公開の状態。サイトには出ていない

左のリスト(作品やニュースの一覧)では、各ドキュメントの横の**小さな丸い印(状態インジケーター)**で状態がわかります。未公開の変更があるものには印が付きます。

### Draft と Published の関係

**Draft(下書き)と Published(公開中)は、同じドキュメントの「編集中バージョン」と「公開バージョン」**です。1つの作品に対してセットで存在します。

- **Published の内容** = 今まさにサイトに表示されているもの
- **Draft の内容** = 編集中のもの。まだサイトには反映されていない

公開中のドキュメントを書き換え始めると、Sanity が自動的に Draft を作り、そちらに変更が入ります。**Publish を押してはじめてサイトに反映**されます。

### 画面上部の「Published / Draft」切り替えについて

この管理画面は、混乱を防ぐために**ドキュメント上部の「Published / Draft」の切り替えボタンと、右上の表示切り替えメニューを非表示**にしています。また「リリース」「予約公開」の機能も使わない設定にしています。

そのため、Sanity 公式の説明やネット上の記事にある「画面上部で Published を選ぶ」「Schedule で予約公開する」といった操作は、この管理画面では出てきません。

覚えておくことはシンプルです:

1. 開いて、書き換える(自動で下書きになる)
2. 右下の **Publish** を押す(サイトに反映される)

### タイトルや画像を変えたとき —「どれがどれ」かわからなくなったら

**Sanity は見た目(タイトル・画像)ではなく、内部のIDで Draft と Published を紐づけています。** タイトルや画像をどれだけ変えても、別の作品と混ざることはありません。

変更内容を確かめたいときは、ドキュメントを開いた状態で右上の **「…」メニュー**や、右上の**履歴(時計のアイコン)**から変更履歴を確認できます。

### 基本の操作

| 操作 | 意味 | 場所 | サイトへの影響 |
|------|------|------|--------------|
| Publish(公開) | 下書きをサイトに公開する | 右下の緑のボタン | 約1分以内に反映 |
| Discard changes(変更を破棄) | 下書きを捨てて公開中の状態に戻す | 右上「…」メニュー | なし |
| Unpublish(非公開) | 公開中をサイトから引っ込める。データは残る | 右上「…」メニュー | 約1分以内に消える |
| Delete(削除) | データごと消す | 右上「…」メニュー | 即時・戻せない |

> **注意:** Unpublish は、公開中のドキュメントにだけ使えます。一度も Publish していない下書きには表示されません。

## 公開済みのコンテンツを編集する

1. **編集したいドキュメントを開く** — 左メニューから作品やニュースをクリック
2. **内容を書き換える** — 書き換えた瞬間に Sanity が自動で下書き(Draft)を作ります。**この時点ではまだサイトは変わりません**
3. **右下の「Publish」を押す** — 下書きの内容でサイトが上書きされます

> 編集途中で「やっぱりやめたい」場合は、右上「…」→「Discard changes」で下書きを捨てられます。サイトに公開されている内容は変わりません。

## 作品(商品)を追加・編集する

左メニューの「**商品**」から行います。

### 新しい作品を追加する

1. 左メニューの「**商品**」をクリック
2. 一覧の上にある **新規作成ボタン(鉛筆または + のアイコン)** を押す — 空の入力フォームが開きます
3. 各項目を入力する(下記参照)
4. 右下の「**Publish**」を押して公開

### 入力項目の説明

| Sanity上の項目名 | 内容 | サイトでの使われ方 | 必須 |
|--------|------|------|:----:|
| 題名 | 作品名 | 一覧・詳細ページの作品名 | ✓ |
| Slug (URL) | URL に使われる英字の識別子。題名入力後「Generate」で自動生成 | `iamaliar.com/gallery/〇〇` の〇〇部分 | ✓ |
| 説明文 | 作品の説明文 | **詳細ページだけ**に表示(一覧には出ない)。改行はそのまま反映 | ✓ |
| 制作ストーリー | 制作背景・コンセプトなど | 詳細ページの「Story」欄 | |
| サイズ表記 | 自由記入(複数追加可) | 詳細ページの「Size」欄に枠付きで並ぶ | |
| 素材 | 素材の説明 | 詳細ページの「Material」欄 | |
| ステータス | 販売中 / Sold (販売済み) / 受注制作 / アーカイブ | 詳細ページ上部に表示(英語表示時は Available / Sold / Made to order / Archived) | ✓ |
| メイン画像 | メインの写真(1枚) | 一覧のサムネイル、詳細ページの1枚目 | ✓ |
| その他の画像 | 追加の写真(複数可。ドラッグで並び替え) | 詳細ページの2枚目以降。**1枚目は一覧でマウスを乗せたときの写真**にもなる | |
| 公開日(表示用・並び順用) | 日付 | 一覧の並び順(新しい順)。未来の日付にしても自動公開はされない | |

> **ステータスについて:** 「Sold」や「アーカイブ」にしても、**Gallery の一覧からは消えません**(詳細ページの表示が変わるだけ)。サイトから見えなくしたい場合は Unpublish してください。

> **Slug について:** 一度公開した作品の Slug を変えると、URL が変わり、古い URL は 404 になります。SNS 等でシェア済みなら変えないでください。

### 既存の作品を編集する

左メニュー「商品」→ 編集したい作品をクリック → 書き換える → 「Publish」で反映。

### 作品を非公開にする / 削除する

- **非公開:** 作品を開いて右上「…」→「Unpublish」— サイトから消えるが、データは残る
- **削除:** 右上「…」→「Delete」— データごと消える。戻せないので注意

> 「ホーム画面ヒーロー」のリンク先に設定している作品は、先にヒーロー側のリンクを外さないと削除できないことがあります。

## ニュース(News)を追加・編集する

ニュースは **カテゴリーによって入力できる項目が変わります**。カテゴリーを選んでから残りの項目を入力してください。

### カテゴリーの種類

| カテゴリー | 用途 | カテゴリー専用の項目 | サイトでの見え方 |
|----------|------|-------------------|---|
| **イベント・展示** | 展示会・ポップアップなど | 開催場所 / Google Maps URL / 開催期間 | 本文の上に Date / Venue / 「Google Maps で見る →」の枠 |
| **お知らせ** | 一般的なインフォメーション | なし | — |
| **着用紹介** | Instagram投稿や掲載ページの紹介 | 投稿・掲載リンク (URL) | 本文の上に「詳細を見る →」リンク |

英語表示のときは、カテゴリー名が Event / Info / Styling になります。

### 新しいニュースを追加する

1. 左メニューの「**ニュース**」をクリック
2. **新規作成ボタン** を押す
3. **カテゴリーをまず選ぶ** — 選択後に専用項目が表示されます
4. 各項目を入力する(下記参照)
5. 右下の「**Publish**」を押して公開

### 入力項目の説明

**全カテゴリー共通**

| 項目名 | 内容 | 必須 |
|--------|------|:----:|
| タイトル | ニュースのタイトル | ✓ |
| Slug | URLの識別子。「Generate」で自動生成 | ✓ |
| カテゴリー | イベント・展示 / お知らせ / 着用紹介 | ✓ |
| 概要(一覧に表示される短い説明) | 一覧ページと詳細ページのタイトル下に表示 | |
| カバー画像 | 一覧のサムネイルと詳細ページ上部の横長画像 | |
| 本文 | 記事本文(下の注意を必ず読んでください) | |
| 公開日 | 一覧の並び順と表示日付。作成時に今日の日時が自動で入る | |

**「イベント・展示」のみ表示される項目**

| 項目名 | 内容 | 入力例 |
|--------|------|--------|
| 開催場所 | 会場の名前・住所など | `代官山 蔦屋書店 2号館` |
| Google Maps URL | 会場の Google Maps リンク | `https://maps.google.com/...` |
| 開催期間 | 開催の日付範囲(自由記入) | `2026.06.15 — 06.30` |

**「着用紹介」のみ表示される項目**

| 項目名 | 内容 | 入力例 |
|--------|------|--------|
| 投稿・掲載リンク (URL) | Instagram 投稿や掲載ページの URL | `https://www.instagram.com/p/...` |

> URL は必ず `https://` から始まる形で貼ってください。それ以外はサイトにリンクとして表示されません。

### 本文についての重要な注意

本文の入力欄には「見出し H2 / H3」「引用」「太字」「斜体」「画像の挿入」のボタンがありますが、**サイトには文字だけが段落として表示されます。**

| 本文で使ったもの | サイトでの表示 |
|---|---|
| 普通の段落 | ✅ そのまま表示 |
| 見出し H2 / H3・引用 | ⚠️ 普通の段落として表示(大きくならない) |
| 太字・斜体 | ⚠️ 装飾なしの普通の文字になる |
| 本文中の画像 | ❌ **表示されない** |

- 段落を分けたいときは Enter で改行して新しい段落にしてください
- 写真を見せたい場合は「カバー画像」を使ってください
- 20文字未満の短い段落や、全角スペースで始まる段落は、少し明るい色で表示されます

## ホーム画面ヒーローを変える

トップページの背景画像とキャプションは「**ホーム画面ヒーロー**」から変更します。作品やニュースと違い、これは1つだけ存在する特別な設定です。

> **現在、この設定は一度も保存されていません**(トップはグラデーション背景だけで表示されています)。初めて使うときも、下の手順で入力して Publish すれば反映されます。

1. 左メニューの「**ホーム画面ヒーロー**」をクリック
2. 変更したい項目を編集する
3. 右下の「**Publish**」を押して反映

| 項目名 | 内容 |
|--------|------|
| ヒーロー画像 | 「I AM A LIAR」の大きなロゴの背景に全面表示される画像。空欄にすると画像なし(グラデーション背景のみ) |
| キャプション(任意) | タグライン「解釈はあなたが決めてください。」の下に、金色の小さな大文字で表示されるラベル。例:「Spring 2026 Selection」「New Arrival」 |
| リンク先の商品(任意) | **キャプションの文字**をクリックしたときに飛ぶ作品ページ。キャプションが空だとリンクも出ません(画像自体はクリックできません) |
| 画像の不透明度(0〜1) | 1 だとくっきり、0.4 くらいだと薄く重なる。空欄なら 0.5。ロゴの文字が読みやすい 0.4〜0.6 あたりがおすすめ |

> 画像はロゴの後ろに大きく敷かれ、上下に暗いグラデーションが重なります。明るすぎる写真より、暗めでコントラストの低い写真の方がロゴが映えます。

## 写真のアップロードについて

サイトではアップロードした画像が**そのままのサイズで配信**されます(自動で縮小されません)。重い画像はページの表示が遅くなる原因になるので、下の目安を守ってください。

### 拡張子(ファイルの種類)について

| 拡張子 | 説明 | 使えるか |
|--------|------|:--------:|
| .jpg / .jpeg | 写真に最もよく使われる形式。軽くて表示が速い | ◎ 推奨 |
| .webp | jpg よりさらに軽い形式 | ◎ 推奨 |
| .png | 背景が透明な画像(ロゴなど)向き。写真には不向き(重い) | ○ OK |
| .heic / .heif | iPhone のデフォルト形式。ブラウザによって表示されないことがある | △ 要注意 |
| .gif | ファイルが非常に重くなりがち | △ 非推奨 |
| .tiff / .raw / .bmp | Web 向きでない | ✕ 不可 |

> iPhone で撮った写真を Safari からそのままアップロードする場合、iOS が自動で JPEG に変換してくれます。

> **Mac 経由の場合**(AirDrop・USB でコピーしてからアップロード): .heic のまま取り込まれることがあります。写真アプリで対象画像を選び「ファイル」→「書き出す」→ 形式を JPEG にして書き出してからアップロードしてください。

### ファイルサイズとピクセル数

- **推奨ピクセル数:** 横幅 1500〜2500px 程度
- **推奨ファイルサイズ:** 1枚あたり 1〜2MB 程度、最大でも 5MB 以内
- 作品の写真は **縦長(3:4)** で表示されます。縦長で撮ると切れにくくなります

### 画像の切り抜き位置(ホットスポット)

画像をアップロードしたあと、画像の上の **鉛筆(編集)アイコン** から「ホットスポット」を設定できます。

> 現在のサイトはホットスポットの設定を使っていません(画像は常に中央を基準に切り抜かれます)。大事な部分が中央に来る写真を選んでください。

### ファイル名のつけ方

日本語のファイル名は文字化けの原因になることがあるので、**英数字・ハイフン・アンダースコアのみ**を使う。

| 良い例 | 避けたい例 |
|--------|-----------|
| `ep-9-front.jpg` | `商品01.jpg` |
| `news-popup-2026.jpg` | `ニュース画像.jpg` |
| `hero-2026-spring.webp` | `IMG 3847.HEIC` |

## 「あれ?」と思ったとき

### Publish したのにサイトに反映されない

配信システムのキャッシュが残っていることがあります。1〜2分待ってから、ブラウザを `Cmd+Shift+R`(Mac)または `Ctrl+Shift+R`(Windows)で強めにリロードしてみてください。

### ニュースの見出しや画像がサイトに出ない

仕様です。本文は文字だけが表示されます。上の「ニュース」章の「本文についての重要な注意」を参照してください。

### 「値段」「カテゴリ」の欄がない

2026年11月に入力項目から削除しました。サイトでは金額を出さず、「¥」の横を白いバーで伏せて「PRICELESS.」と表示し、LINE での問い合わせに誘導しています(この表示はコードで固定)。詳細ページ下部の「Related Works」には、ほかの作品が新しい順に最大3件表示されます。

### アーカイブ / Sold にしたのに一覧に残っている

仕様です。ステータスは詳細ページの表示を変えるだけです。一覧から外したいときは Unpublish してください。

### 画像がサイトに表示されない

- 該当ドキュメントの画像欄が空になっていないか確認
- .heic のまま使っていないか確認。なっていたら JPEG に変換して再アップロード
- ファイル名に日本語が入っていないか確認

### アップロードが途中で止まる / エラーになる

ファイルサイズが大きすぎる可能性があります。10MB 以上のファイルは一度圧縮してから試してください。ブラウザをリロードして再度試す。

### Publish ボタンが押せない / グレーアウトしている

必須項目が未入力の場合に起きます。作品なら「題名・Slug・説明文・ステータス・メイン画像」、ニュースなら「タイトル・Slug・カテゴリー」。赤いエラー表示の項目を確認して、すべて入力してから再度試してください。

### ニュースのカテゴリー専用項目が表示されない

カテゴリーを選択すると専用の入力欄が表示されます。表示されない場合は画面を一度スクロールしてみてください。

### 「Journal」がメニューにない

2026年11月のリニューアルで Journal ページは廃止され、管理画面のメニューからも削除されました。読み物的な発信は News の「お知らせ」を使ってください。
