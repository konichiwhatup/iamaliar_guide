# I AM A LIAR — サイト概要

## 概要

このドキュメントは iamaliar.com の全体像をまとめたものです。どんなページがあるのか、どこを Sanity で変えられて、どこがコードに書かれているのかを説明します。

コンテンツの更新方法(Sanity の使い方)は [Sanity 使い方ガイド]({{ "/sanity/" | relative_url }}) にまとめています。

- **サイトURL:** https://iamaliar.com(`https://www.iamaliar.com` でも同じサイトが開きます)
- **サイトタイトル:** Old, yet new — myself
- **初版:** 2026年4月 / **最終更新:** 2026年11月8日(ページ構成の大幅リニューアルを反映)

## どんなページがあるか

サイトは全部で5つのページで構成されています。上部メニューの並び順と同じです。

| メニュー | URL | 中身を変える場所 |
|---|---|---|
| Home | `iamaliar.com/` | ヒーロー画像・キャプション → Sanity / それ以外の文章 → コード |
| Philosophy | `iamaliar.com/philosophy` | コード(Sanity では変えられない) |
| Gallery | `iamaliar.com/gallery` | Sanity の「商品」 |
| News | `iamaliar.com/news` | Sanity の「ニュース」 |
| Contact | `iamaliar.com/contact` | コード(Sanity では変えられない) |

> 以前あった **Collection(`/collection`)は Gallery(`/gallery`)に名前が変わり**、**Journal(`/journal`)は削除**されました。古い URL は「ページが見つかりません(404)」になります。SNS やショップカードに古い URL を載せている場合は差し替えてください。

### Home(ホーム)
`iamaliar.com/`

ブランドの入口となるページ。

1. **ヒーロー** — 画面いっぱいに「I AM A LIAR」の大きなロゴと「解釈はあなたが決めてください。」のタグライン。背景画像とその下の小さなキャプションは Sanity の「ホーム画面ヒーロー」で設定できます(未設定ならグラデーション背景だけになります)。
2. **Brand Story** — 「古くて、新しい、私」の見出しに続き、5つの短い章(「I AM A LIAR」/「衝撃を、纏う。」/ 額縁に飾れる服作り / 既製品を物語のある一点ものに変換する /「刺し子」)。**文章のみで、写真はありません。**

> 現在、Sanity に「ホーム画面ヒーロー」の設定が 1 件も保存されていません。そのためトップはグラデーション背景だけで表示されています。画像を出したい場合は [Sanity 使い方ガイドのホーム画面ヒーロー]({{ "/sanity/" | relative_url }}) を参照してください。

### Philosophy(フィロソフィー)
`iamaliar.com/philosophy`

「NOT FOR WEARING.」と題したインタビュー形式のページ。

- 冒頭: ブランドの成り立ち(2024年に2人で始めたこと、1着に約3週間・20を超える工程、すべて1点もの)
- Q&A 6問: 名前の意味 / NOT FOR WEARING. の意味 / 古い素材を選ぶ理由 / 刺し子 / 襤褸と不均一の美しさ / 目指すもの
- 締め: 「I AM A LIAR.」

文章はすべてコードに書かれています。変更したい場合は [運用マニュアル]({{ "/operations/" | relative_url }}) の手順で修正します。

### Gallery(ギャラリー)
`iamaliar.com/gallery`

作品(商品)の一覧ページと、各作品の詳細ページで構成されています。

**一覧ページ**
- スマホは2列、PCは3列で作品が並びます。表示されるのは**写真・通し番号・作品名だけ**です(価格や説明文は出ません)
- PC でマウスを乗せると、「その他の画像」の1枚目に切り替わります
- ページ下部に価格欄(「¥」+ 白いバーで伏せた金額、「PRICELESS.」)と「LINEから問い合わせる⇨」のリンク
- 作品が1件もないときは「作品を準備中です」と表示されます

**詳細ページ**(`iamaliar.com/gallery/〇〇`)
- 左: 写真(メイン画像 + その他の画像)。サムネイルで切り替え、クリックで拡大表示。拡大中は ← → キーで送り、Esc で閉じる
- 右: ステータス(販売中 / Sold / 受注制作 / アーカイブ)→ 作品名 → 説明文 → Size → Story → Material
- 価格欄: **金額は表示しません。**「¥」の横を白いバーで塗りつぶし、「PRICELESS.」「LINEから問い合わせる⇨」「価格についてはお問い合わせください」を表示
- 下部: 「Related Works」として**ほかの作品を新しい順に最大3件**表示

### News(ニュース)
`iamaliar.com/news`

イベント・展示情報、お知らせ、着用紹介を発信するページ。

- 一覧: カバー画像(あれば)・カテゴリ・日付・タイトル・概要を新しい順に表示
- 詳細: カバー画像 → カテゴリと日付 → タイトル → 概要 → イベント情報(日時・会場・Google Maps リンク)または「詳細を見る →」リンク → 本文
- 投稿が1件もないときは「ニュースを準備中です」と表示されます

### Contact(コンタクト)
`iamaliar.com/contact`

お問い合わせページ。

- 見出し「あなたの解釈を聞かせてください。」
- **LINE ボタン**(公式LINEはこちらから)と **Instagram ボタン**(Instagramを見る)
- 「作品について」「オーダー」の案内文
- **FAQ**(現在1問:「商品の購入をしたい場合はどうすればいいですか」)

### 共通部分

- **ヘッダー(PC):** 中央に Home / Philosophy / Gallery / News / Contact、右端に JP / EN 切替
- **ヘッダー(スマホ):** 左に三本線メニュー(押すと左からメニューが出る)、中央にロゴ「IAMALIAR」(押すとホームへ)、右に JP / EN 切替
- **フッター:** ロゴ「IAMALIAR」、© 年 IAMALIAR. All rights reserved.、タグライン「Old, yet new — myself.」
- **404:** 存在しない URL では「Page Not Found」とホームへ戻るリンクを表示

### 日本語 / 英語の切り替え

右上の JP / EN ボタンでいつでも切り替えられます。選んだ言語はブラウザに記憶され、次に開いたときもそのまま表示されます。

ただし**切り替わるのはコードに書かれた文章だけ**です(メニュー、Brand Story、Philosophy、Contact、ボタン類など)。Sanity で入力した作品名・説明文・ニュース本文などは、入力した言語のまま両方の表示で同じものが出ます。

## デザインについて

ブランドコンセプト「I AM A LIAR」の持つ矛盾と美しさを、余白と暗さで表現するデザインにしています。

### カラー

| 色 | 用途 |
|---|---|
| ⬛ **#0a0908** | 背景色。わずかに茶色を含んだ黒 |
| ⬜ **#e8e2d8** | メインのテキスト色。生成りのようなオフホワイト |
| 🟫 **#c4a87c** | アクセント色。くすんだゴールド。リンク、Philosophy の質問文、ヒーローのキャプション、ローダーなど |
| ◼ **#6b6560** | サブテキスト。本文の補足や説明文 |
| ▪ **#1c1c1c** | 区切り線 |

画面全体に、ごく薄いノイズ(フィルムの粒子のような質感)を重ねています。

### フォント

- **Cormorant Garamond** — 欧文の見出し(I AM A LIAR のロゴなど)。繊細なセリフ体
- **Noto Serif JP** — 日本語の見出し・本文。細めの明朝体
- **Noto Sans JP** — 一部の UI
- **DM Mono** — ラベル、番号、日付などの小さな英数字。等幅でクールな印象

### アニメーション

- ページを開いたときのローダー(「iamaliar — loading」と金色のライン、約2秒)
- ヒーローのロゴがゆっくり浮かび上がり、スクロールすると奥へ沈むように薄れる
- コンテンツが画面に入ると滑らかにフェードイン

> 以前あった「カーソルの追従演出」は現在は使っていません。

## サイトがどこで動いているか

難しい話はなるべく省きます。知っておくと便利な部分だけ。

### ドメイン

サイトのアドレスは `iamaliar.com` です。Cloudflare というサービスで取得・管理しています。毎年自動更新されるので、基本的に意識しなくて大丈夫です。

### サーバー

Cloudflare の世界中に分散したサーバーで動いています。どこからアクセスしても近くのサーバーが応答するため、速く表示されます。

### コンテンツ管理

作品(商品)・ニュース・ホームのヒーロー画像は **Sanity** というサービスで管理しています。管理画面から追加・編集・削除ができます。操作方法は [Sanity 使い方ガイド]({{ "/sanity/" | relative_url }}) をご覧ください。

それ以外の文章(Brand Story、Philosophy、Contact、FAQ、ボタンの文言など)はサイトのコードに直接書かれています。

| 変えたいもの | 変える場所 |
|---|---|
| 作品の追加・写真・説明文・ステータス | Sanity「商品」 |
| ニュースの追加・編集 | Sanity「ニュース」 |
| トップの背景画像・キャプション | Sanity「ホーム画面ヒーロー」 |
| Brand Story / Philosophy / Contact / FAQ の文章 | コード(`src/lib/i18n.ts`) |
| LINE・Instagram のリンク先 | コード |
| 価格欄の見せ方(¥ + 白いバー / PRICELESS. 表記) | コード |

### セキュリティ

- URL が `https://` から始まる暗号化通信(www なしでも www ありでも)
- Cloudflare のファイアウォールで不審なアクセスをブロック
- ブラウザ向けのセキュリティ設定(読み込める画像・スクリプトの制限、他サイトへの埋め込み禁止など)を全ページに付与

> 特別なメンテナンスなしで安定して動き続ける設計になっています。基本的に「何もしなくていい」状態です。
